🌵 PalmillaBot

Agente de IA (Ingeniero Forestal) para obtener los permisos de aprovechamiento de recursos forestales no maderables — tallos de Yucca (palmilla) — en Baja California, y para generar el Programa de Manejo Forestal Simplificado ante la SEMARNAT.

LGDFS Art. 85 Reglamento Art. 57 NOM-005-SEMARNAT-1997 NOM-059-SEMARNAT-2010 SEMARNAT-03-052 FF-SEMARNAT-074 Google Gemini

Datos del predio

Complete los datos para que el agente determine la vía de trámite y el checklist de permisos.

1 · Datos del titular (propietario o poseedor)
2 · Datos técnicos y de ubicación del terreno
3 · Datos de identificación oficial y registro
4 · Datos legales y de autoridad

Complete el formulario y presione Analizar predio para ver la vía de trámite, el checklist y las citas legales.

Consulta normativa (Módulo A — RAG + Gemini)

Pregunte sobre la normatividad. El agente recupera las disposiciones aplicables del corpus legal (LGDFS, Reglamento, NOM-005, NOM-059) y, si hay una API key de Gemini configurada, redacta una respuesta citada con IA.

Hola 👋 Soy PalmillaBot. Pregúntame, por ejemplo: «¿Se necesita aviso o autorización para aprovechar tallos de Yucca?», «¿Cuál es el ciclo de corta?» o «¿Qué documentos exige el programa de manejo?».

Generador del Programa de Manejo Forestal Simplificado

Genera el documento técnico con la estructura de 6 secciones (Reglamento LGDFS Art. 57 + NOM-005 §4.1.4). Usa los datos del formulario de la pestaña Análisis. Con IA (Gemini) se redacta una versión narrativa completa; sin IA se usa la plantilla determinista.

📄

El documento generado aparecerá aquí, con opciones de descarga en PDF, DOCX, HTML y Markdown.

⚙️ Configuración de la IA (Google Gemini)

Pegue aquí su API key de Google AI Studio para activar las respuestas redactadas por IA. La clave se guarda localmente en config.json (nunca se sube a GitHub) y también puede definirse con la variable de entorno GEMINI_API_KEY.

¿Cómo obtener una API key de Gemini?

  1. Entra a Google AI Studio → API keys.
  2. Inicia sesión con tu cuenta de Google.
  3. Pulsa «Create API key» y copia la clave (empieza por AIza…).
  4. Pégala en el campo de la izquierda y pulsa Guardar configuración.
  5. Pulsa Validar conexión para comprobar que funciona.
Privacidad: la clave se guarda solo en su computadora (config.json, permisos 600). PalmillaBot no envía su clave a ningún servidor propio; las consultas van directamente a la API de Google.
Sin API key: el sistema sigue funcionando en modo RAG offline: recupera y cita las disposiciones legales, y genera el Programa de Manejo con la plantilla determinista, pero sin redacción por IA.
